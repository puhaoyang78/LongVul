# 基线复核和 LongVul 机制诊断

## 口径

当前 LongVul 和匹配均匀对照使用 `efa10f4` 的固定 32 BPE、512 位置和 Global Fusion。困难实验来自 `a367adf` 和 `efa10f4`，历史 Coarse-to-Fine 与既有干预分别来自 `60688d2`、`8674e25`。沿用 PrimeVul_original 的 8,708 / 1,124 / 1,128 个 Train / Valid / Test 函数。四个外部对照保持各自训练与早停规则。共同长度口径使用原始 CodeBERT BPE，配对按两侧较大长度分组。模型选择使用完整 Valid MCC，正式测试使用 `p > 0.5`。[汇总结果](../baseline_completion/summary.json) · [历史机制分析](../coarse_to_fine_diagnosis/report.md)

LongVul 三种子整体和长组平均 MCC 为 0.1065 和 0.1007，较最高外部对照 StagedVulBERT 分别高 0.0149 和 0.0283。CodeBERT ≥2041 组相对 SEA 的优势为 0.0090。SEA 的配对排序更好，Seed 42 的 Uniform-4 整体 MCC 也超过对应 LongVul。LongVul 的端到端推理均值为 36.68 秒，在三种多窗口外部方法中均更快，Uniform-4 平均为 13.61 秒。完整配对指标、单种子结果和样本标准差见统一汇总。

## 固定检查点检索干预

辅助头比较所有块、原生中心、精细布局覆盖、同布局均匀权重、均匀采样布局及未覆盖区域。部分覆盖按块内 Simple BPE 份额计算，随后各组重新归一化。均匀采样布局保留对应的索引权重，改变的是区域。保留旁路的模型另将头输入的全局向量置零，Query 仍使用原先的全局向量。空子集单列为不可用，公用比较采用各子集均有效的同一批函数及完整配对。块向量可能包含同一窗口内其它位置的上下文。

当前索引器的 CodeBERT 长组平均选中 29.1% 的块作为中心，全部精细输入覆盖其 67.7% 的注意力质量。≥2041 组分别为 17.9% 和 44.5%。A、C、D 在超长组的覆盖质量分别为 52.3%、49.5%、49.8%。共同比较含 651 个函数、316 个完整配对。当前辅助头的全量 / 可见 / 丢弃区域 ROC-AUC 分别为 0.5358 / 0.5398 / 0.5290，屏蔽全局旁路后为 0.5381 / 0.5360 / 0.5316。C、D 可见区域的 AUC 与全量相差不到 0.002，BCE 分别上升约 0.008 和 0.006。超长函数有较多注意力质量落在未选区域，但可见区域保留了这一固定辅助头测得的大部分排序能力。[权重覆盖及六种干预](auxiliary.json)

精细干预固定同一种子的全局表示和精细分类参数，四种布局同时用于正常及困难模型。在原生布局外，复用独立块检索与匹配均匀输入。纯外部布局只从原生布局的补集填充，优先长区间，512 个位置包含分隔符。共同比较使用补集足够的函数，配对要求两侧都满足。不同布局可能有不同数目的正文和分隔符。固定模型替换输入产生分布变化，本次复用历史 13,459 次反馈记录作为背景。

三个正常检查点的完整 Valid MCC 在中心上下文布局下分别为 0.1050、0.1050、0.1111，换独立中心后为 0.0854、0.0748、0.0877，换均匀后为 0.0666、0.0669、0.0839，按 42、1234、123456 排列。纯外部对照在每个种子的共同队列均有 423 个函数和 205 个配对。该队列的 Seed 42 中，原生和纯外部的 MCC 为 0.0772 与 0.0420，AUC 为 0.5152 与 0.5467。B 更换到纯外部布局的平均概率绝对变化仅 6.23×10⁻⁷，正常对应模型约为 0.480。匹配均匀停滞组的变化约为 0.0010，正常 Seed 1234 约为 0.184。训练状态影响了模型能从不同布局中表现出的敏感性。原生选段在正常模型的固定阈值上有可测价值，纯外部也保留了部分排序信息。[等预算逐样本干预和分层结果](fine.json)

## 原始位置和冻结表示

`92453aa` 曾把 64 档归一化位置、窗口及间隔编码注入 CodeBERT 词向量，位置组在固定阈值下出现单类预测。本轮保持冻结 UniXcoder 的嵌入和位置索引。顺序诊断只交换已有块向量，按身份逆置换后比较 QK 分数。Token 位置对照在冻结编码之后加固定的原始 BPE 正弦编码，轻量读出参数初始化与无位置组一致。

完整 Valid 的 1,124 个函数上，全局向量、按块身份恢复的索引分数和辅助预测最大绝对变化分别为 4.77×10⁻⁷、5.96×10⁻⁸ 和 1.19×10⁻⁷，0 个阈值判定改变。Mean/Max 与逐块 Key 的组合不显式感知块的原函数位置或跨窗口顺序。冻结 UniXcoder 窗口内的原生位置仍已编码在每个向量中；源码打包保留选中 Token 的相对源顺序，片段间只使用 SEP，原始间隔长度不传入精细位置索引。[置换逐样本与汇总](../representation_diagnosis/permutation.json)

特权 Oracle 块诊断的整体、长组和超长组 MCC 分别为 0.0780、0.0589 和 0.0551，整体 AUC 为 0.5541。Oracle 按历史 Diff 保留规则构造输入，与普通对照隔离。各块组用相同单 Query 分类头独立训练 16 轮，并按每块实际覆盖比例作为注意力的质量权重。部分覆盖的块向量仍来自整块聚合。Dense 的结果只反映这一冻结表示与轻量读出的组合。

完整块表示能提供判别信息，Predicted 相对 Uniform 的整体 MCC 高 0.0256，和 Dense 相差 0.0081。超长组从 Predicted 的 −0.0001 上升至 Oracle 的 0.0551，说明该组保留位置仍有改进空间。真实 Diff 引导的块读出整体 MCC 低于当前精细编码，这个比较同时改变了读出和全局残差。在相同布局且都去掉全局残差时，冻结 Token 的整体 MCC 比 Predicted 块高 0.0044，长组低 0.0051。在保留全局残差的对照中，显式原始位置的整体 MCC 提高 0.0033，超长组略降。两组冻结 Token 读出均低于原始源码重编码。

逐条核对了原始 BPE、Simple 位置、窗口内下标以及冻结 Token ID，并复现正式模型的 Valid/Test 选段。Test 由冻结编码提取 472,803 个选中 Token，完整读取 4,432 个窗口、1,949,749 个有效位置，编码与取回耗时 6.24 秒，轻量头耗时 0.63–0.66 秒。三个划分在训练期间共享约 6.54 GiB 的选中 Token 内存，Token 缓存磁盘占用为 0。块头在缓存上的 Test 读出约 0.32–0.36 秒。布局由已存在的块缓存决定，冻结 Token 特征另行提取。窗口上下文可以包含选段以外的代码，分项计时和信息范围与精细重编码不同。[各探针逐轮记录、两种长度口径及成本](../representation_diagnosis/summary.json)

## 下一项待验证假设

优先固定现有检索布局、数据和优化器，只比较**让精细分支先独立预热，再恢复原 Global Fusion**是否减少全量训练平台。直接证据是停滞模型对完全不同的精细布局近乎不敏感、较小的精细编码器位移，以及同一布局在 128 个真实样本上仍可明显降损。晚期全局分支占优和早期优化停滞的因果顺序仍待验证。保持固定阈值 MCC 与排序指标并行记录，避免把校准变化当作训练修复。
