# LongVul 与上一版 Coarse-to-Fine 的机制诊断

当前最有直接证据的瓶颈是 **512 位置内的候选选择**。大块与关联捆绑先压低可保留修改的上限，实际排序和取段又留下更大的覆盖缺口。固定当前分数改用纯中心布局，三个种子的超长组 MCC 都提高。融合端的两个粗分支投影近乎共线，精细表示主导函数分类，粗表示仍能帮助配对排序。

## 诊断口径

当前版使用 `3a82c39` 的 Full 最佳检查点，上一版使用 `60688d2` 的 Joint 最佳检查点。两版各使用 Seed 42、1234、123456，沿用 PrimeVul_original 的 8,708 / 1,124 / 1,128 个 Train / Valid / Test 函数。Train 用于 Seed 42 的全量索引统计和三组预算匹配反馈的回放。Oracle 的 Train 部分由种子 42 按每对最长函数的长度分四层，每层抽 64 对。Valid 和 Test 均使用完整划分，长度按原始 BPE 分组。Test 在 Valid 核对完成后运行，使用相同的布局与预算规则，替代阈值只从 Valid 产生。[Train 索引统计](train_seed42.json) · [Train Oracle](oracle_train.json)

精细输入干预在每个检查点固定分类器、全局表示、加权块表示和源索引分数。两版分类器读取同一批布局，保持原始源码顺序、512 位置打包与原批次大小。对照包含当前关联区域、当前分数的 128 独立中心、每个区域至多增加 64 个位置的关联区域、历史 Uniform Sampling，以及旧 32 BPE 索引器的实际布局。另做三项控制。固定联合检索选中的中心、去掉显式关联后重填。把旧分数搬到 128 独立块。把新分数搬到旧 32 粒度与取段器。搬运按块内均匀分布、按 BPE 重叠分配分数质量，后一项只能检验布局粒度，无法恢复新分数在 128 块内未学到的排序。

表示屏蔽在各模型原生布局上进行。当前版分别屏蔽投影后的 `g`、`z_g`、`z_f`，另以均匀权重重算 `z_g`。旧版在非线性表示层内合并 `g` 和 `z_g`，因此报告可直接解释的粗分支、精细分支及均匀权重结果。固定检查点的输入和表示干预测量模型当前的依赖性，重新训练后的效果仍待验证。[冻结推理代码](https://github.com/puhaoyang78/LongVul/blob/8674e25eafe3ef15c29a102cc2dd918970a91955/diagnostics/coarse_to_fine.py)

相同的 128 纯中心打包下，换旧分数把 Seed 42 长组修改保留率从 44.05% 提到 47.06%，当前检查点长组 MCC 从 0.0538 升到 0.0741。固定旧 32 取段器时，用旧分数比新分数多保留 4.61 个百分点的修改 BPE，旧检查点长组 MCC 为 0.0998 对 0.0503。把旧布局直接交给当前检查点得到 0.0571，旧布局的检测优势依赖检查点。固定联合中心去掉显式关联时，虽然保留更多修改 BPE，两个 Seed 42 检查点的长组 MCC 均下降。关联内容提供了可用信息，强制它参与分配又会改变其他中心的入选。

在可完全解析的 Test 长函数上，两种布局共同保留锚点后，联合布局与纯中心的关联共保留率为 98.97% 对 61.41%，与保持中心再填充的对照为 98.81% 对 76.23%。不同对照的共同锚点集合各自固定。Seed 42 当前检查点改为均匀布局的长组 MCC 差为 +0.0291，按官方配对重采样的 95% 区间为 −0.0359 至 +0.0958。完整分组保存 MCC、F1、ROC-AUC、PR-AUC 和 Pairwise Correctness，配对长度取两侧较长的原始长度。[Seed 42 Test 完整结果](test_seed42.json)

三个种子在当前检查点上改为纯中心，Test 长组平均 MCC 增加 0.0262，≥2041 组增加 0.0825（3/3 提升）。保留原中心再重填的超长组平均增量为 0.0207，单候选关联限额的增量为 0.0100。这将部分收益指向换中心的空间。旧分数在相同 128 纯中心打包下多保留 3.01–3.88 个百分点的长组修改 BPE，在相同 32 取段器下多保留 3.75–5.90 个百分点。同一 128 纯中心打包用旧分数时，当前分类器的超长组平均 MCC 比用新分数低 0.0741。修改定位较好与识别收益之间存在明显差距。

换成均匀输入后，当前检查点的长组 MCC 平均提高 0.0475（3/3），旧检查点平均下降 0.0174（1/3 提升）。同一套旧 32 实际布局换到当前检查点后，长组平均提高 0.0170（2/3）。选段的检测价值与训练过的分类器相互依赖。三组干预支持优先处理候选粒度和分配方式，也表明单独更换索引分数无法稳定修复分类表现。[Seed 1234 Test](test_seed1234.json) · [Seed 123456 Test](test_seed123456.json)

## 5. 阈值、训练与泛化

正式指标始终使用 `p > 0.5`。额外诊断用全量 Valid 在每个检查点和布局上选一个 MCC 最大阈值，平局时取最接近 0.5 的阈值。分类概率排序仍用原始分数。另用 Valid 的平均 logit 差构造一个只平移原布局 logit 的对照，检测整体偏移可解释的部分。

Seed 42 当前模型在 Test 长组换用均匀布局后，真阳性从 230 增至 261，假阳性从 215 增至 238，正类预测率从 60.79% 升至 68.17%。MCC 由 0.0624 升至 0.0915，ROC-AUC 由 0.5447 降至 0.5418，PR-AUC 由 0.5405 降至 0.5267。Pairwise Correctness 由 14.44% 升至 15.78%，配对排序正确率由 56.42% 降至 53.74%，平均配对概率差从 0.00928 降至 0.00725。两类平均概率分别上升 0.0096 和 0.0113。仅加 Valid 得到的常数 logit 偏移时 MCC 为 0.0464，说明接近阈值的样本发生了不同方向和幅度的移动。将两个布局各自的 Valid 最优阈值 0.54871 和 0.49052 用于 Test 长组后，MCC 为 0.0418 和 0.0628。[Test 阈值与混淆矩阵](test_seed42.json)

| --- | ---: | ---: | ---: |

Seed 1234 和 123456 的 AUC 也提升。仅平移 logit 时其长组 MCC 分别为 0.0447 和 0.0350。均匀布局的变化同时包含概率偏移及样本间排序变化，不同种子的相对作用不同。
